Stack: HTML, CSS, Basic JS, Responsive Design

This was a fully self-directed project with the primary focus being to highlight my design and development skills which had drastically improved since my first website 'Hot Beans Web'. This is what I would call my first "proper" website in the sense it actually looks like a professional made website (ish), however its not fully functional, for example, the form doesn't actually sent any data as it felt too far out of my realm to try and work out to do that. I experimented a lot with different features and designs here for different sections of the site, and spent a long time wireframing and building up an idea of what I actually want it to do before I even dove into development. I focused on trying to use the correct semantic tags, using soft gradients that properly match the theme of the website (plumbing), experimented with clip-path in CSS, experimented with transitions, trying to really get those smooth, seamless transitions for great UX, focused on responsive design, had a plethora of root variable for all kind of things such as padding and border-radii and learnt some basic JavaScript such as how to toggle a button. You can view my site here: https://tcurry-git.github.io/AquaFix-Plumbing/
